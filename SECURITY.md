# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Use GitHub's private vulnerability reporting instead: [report a vulnerability](https://github.com/Cartooli/study-kit/security/advisories/new). Include:

- what the issue is and where it lives (file, command or page)
- steps to reproduce, or a minimal example
- the impact you expect

We aim to acknowledge reports within 5 business days and will agree a fix and disclosure timeline with you.

## Scope

In scope: the Study Kit web app, its service worker and kill switch, and anything that could expose a learner's data or run untrusted content. Out of scope: third-party services the app links to.

## Supported versions

Only the latest commit on the default branch is maintained.
